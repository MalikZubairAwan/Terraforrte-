# TerraForte Tiles

A premium tile showcase website built with plain HTML, CSS and JavaScript (no frameworks).

## Features
- Animated intro, hero with live wall visualizer (pick a tile and see it on the wall)
- 13 tile designs generated in code, with hover animation on each card
- Category filters, search, wishlist (saved in localStorage) and compare up to 3 tiles
- Tile details view with a project calculator (tiles needed and estimated cost)
- Project gallery with a before/after slider, FAQ accordion, quote form with validation
- Tile Finder quiz with animated match scores, sort and search, print-ready spec sheet, image zoom on the details view
- Visualizer can apply the tile to the wall, the floor or both
- Process timeline, confetti on quote submit, cursor glow, scroll animations
- Dark / light theme, scroll animations, counters, responsive layout

## Run
Open `index.html` in a browser (or use the VS Code Live Server extension).

## Customise
- Social links and WhatsApp number: edit `WA_NUMBER` and `SOCIAL` in `script.js`
- Real photos and videos: put files in `images/` and `videos/`, then fill the `MEDIA` object in `script.js`
- Tile names, prices and specs: edit the `tiles` array in `script.js`
